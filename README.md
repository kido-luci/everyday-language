# Everyday Language

Learn the English you'll actually use — words you meet in real life, practised
until you can produce them, not just recognise them.

Scaffolded from
[flutter-starter-template](https://github.com/kido-luci/flutter-starter-template)
with `fst create --minimal --database drift`: local-only, no account required,
everything on device.

## Getting started

```sh
./tool/setup.sh      # one-shot bootstrap of a fresh clone
fvm flutter run
```
